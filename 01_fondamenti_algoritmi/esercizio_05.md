# Esercizio 05 — Tradurre un algoritmo informale in pseudocodice

## DESCRIZIONE

L'esercizio richiede di tradurre in pseudocodice un semplice algoritmo che legge un numero intero `N` e distingue tre casi:

- `N > 0`;
- `N < 0`;
- `N = 0`.

L'obiettivo è usare una struttura condizionale completa e mantenere distinti input, output e istruzioni operative.

## SOLUZIONE

### INPUT

Numero `N`.

### OUTPUT

`POSITIVO`, `NEGATIVO` oppure `ZERO`.

### PSEUDOCODICE

```text
CHIEDI all'utente il numero N
LEGGI N

SE N > 0
    STAMPA POSITIVO
ALTRIMENTI SE N < 0
    STAMPA NEGATIVO
ALTRIMENTI
    STAMPA ZERO
FINE SE
```

## COSA HO IMPARATO IN QUESTO ESERCIZIO

- Tradurre una descrizione informale in pseudocodice strutturato.
- Distinguere chiaramente input, output e istruzioni dell'algoritmo.
- Usare correttamente una catena `SE / ALTRIMENTI SE / ALTRIMENTI`.
- Gestire in modo completo tre casi mutuamente esclusivi.
- Rispettare esattamente l'output richiesto dalla consegna.
- Usare `LEGGI N` come forma essenziale per acquisire un valore in pseudocodice.

## ARGOMENTO D'ESAME

Fondamenti degli algoritmi: pseudocodice, selezione/condizione e rappresentazione strutturata di un algoritmo.

Non ancora analizzata in questo esercizio.
